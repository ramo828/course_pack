# course_pack

Multilingual programming, embedded-systems, and IT-support lessons.
The networking curriculum now includes 15 modules in Azerbaijani, Turkish,
English, and Russian, with localized diagrams and quizzes. It includes
step-by-step Windows, Linux, and macOS installation guidance, computer
components, operating-system history, and VirtualBox/VMware virtualization.

Versioned release notes are available in `changelog.json`. The `releaseNotes`
field in `meta.json` points to this JSON file; entries include an ISO-formatted
release date and localized titles, summaries, and change lists for display
during course updates and on the app's About screen.
