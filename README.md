# course_pack

Multilingual programming, embedded-systems, and IT-support lessons.
The networking curriculum now includes 13 modules in Azerbaijani, Turkish,
English, and Russian, with localized lesson diagrams and quizzes.

Versioned release notes are available in `changelog.json`. The `releaseNotes`
field in `meta.json` points to this JSON file; entries include an ISO-formatted
release date and localized titles, summaries, and change lists for app display.
